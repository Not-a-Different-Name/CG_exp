## 交付顺序

1. **补齐基准实机证据。** 在森林场景用 Tab 选中机器人。分别演示整体平移、旋转和缩放，切换多视图并拖动窗口，验证 Esc、菜单退出和窗口关闭。用解压后的交付包再走一遍，并在可用的另一台 Windows 机器验证。
2. **用模板完成报告。** 报告全稿已写入 [REPORT_DRAFT.md](REPORT_DRAFT.md)（八栏 + 14 项评分对照），答辩要点见 [DEFENSE_CARDS.md](DEFENSE_CARDS.md)。剩余：粘贴进 `report.doc`、补封面学院/专业/指导教师、按证据路径插图。按课件要求补齐 AI 使用说明与现场演示流程。
3. **机器人导入加分（已完成）。** `i` / `Shift+I` / `k` 三种形态切换，随程序附带 TrailSurveyor 样例。静态 OBJ 可整体变换；带关节的导入模型仍需部件分组与支点，列为后续扩展。
4. **定稿课程交付包。** 按已确认的提交清单整理报告与运行材料。目前 `dist/` 内为 11 月 14 日的复查包。

## 复验命令

```powershell
.\build.bat x64
ctest --test-dir build -C Release --output-on-failure
.\build\Release\viewer.exe --selftest
python tools/render_smoke.py --out out/status-20261121/render
python tools/update_manifest.py --check
```

录制需要 PATH 中的 FFmpeg / FFprobe。换机时可运行 `powershell -NoProfile -File tools/setup_dependencies.ps1` 检查构建与录制依赖。复查视频可用 `python tools/record_demos.py` 重录。
