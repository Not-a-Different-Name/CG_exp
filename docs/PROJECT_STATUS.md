# 2026 计算机图形学实验要求与完成状态

核对日期为 2026 年 11 月 27 日，程序版本为 `d5fb4b4`。按 2026 年课件第 8–11 页逐项核对，6 项基准要求和 8 项加分方向均有对应实现。根目录预编译程序通过 42 条自检和 24 组 OpenGL 出图。完整源码构建中的 OBJ 单元测试目前存在链接错误，键鼠操作、连续缩放窗口和手动退出仍待现场确认。

课程原始依据为本地 `CG Experiments - 2026.pptx`（共 13 页）和 `report.doc`。本报告各项标注了对应课件页码。

| 课件要求 | 内容与状态 |

## 验证结果

| 验证 | 2026 年 11 月 27 日结果 |
| --- | --- |
| Release x64 源码构建 | CMake 的 `viewer` 目标通过。 |
| CTest | `math_camera` 通过。完整构建在 `obj_loader_test` 链接阶段报 LNK2019，原因是 OBJ 加载器引用的 `appLogStage` 由 `app.cpp` 提供，而独立测试目标未链接该文件。该测试在本版本待修复后复验。 [目标定义](../CMakeLists.txt) · [OBJ 加载器](../src/obj_loader.cpp) |
| 预编译程序自检 | 42/42 通过，覆盖相机、拾取、机器人层级、曲线、分形、动物行为与追赶。弧长步进 0.15 时，位移误差小于 0.005 个场景单位；追赶朝向点积实测 0.999。 |
| 预编译程序 OpenGL 出图 | 24/24 通过，含森林、展示台、投影、四视口、线框、阴影与经典模式对照、机器人姿势、动物、曲线、追赶及 OBJ／PNG 导入。实际宽屏出图为 1600×300。 [出图脚本](../tools/render_smoke.py) |
| 皮肤与启动路径 | 无窗口检查接受 64×64 Classic／Slim、64×32 旧版、128×128 高清样本，并拒绝 48×48 样本。把预编译程序与模型放入含中文的目录后，仍可加载默认兔子并输出截图。 |
| 既有视频 | 用 FFprobe 复核 4 段 H.264 视频，均为 960×600、24 fps。挥手、路径、动物和追赶片段分别为 4、10、16 和 8 秒。 [视频与抽帧目录](../report-assets/review/video/) |
| 现场与异机 | 待验收项目包括整体变换、相机漫游、中键菜单、文件对话框、连续窗口缩放、手动退出及另一台 Windows 机器运行。自动截图验证覆盖指定尺寸和命令行入口。 |
